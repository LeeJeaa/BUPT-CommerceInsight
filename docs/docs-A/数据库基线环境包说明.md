# 数据库基线环境包说明

> 负责人：成员 A  
> 目的：提供 PostgreSQL 基线环境，用于验证 A 的 `sql/V*.sql` 源资产可以通过 Docker 初始化联动执行。  
> 边界：这是开发基线环境，不替代 D 的正式 dbgen、COPY、SF=0.6/SF=1 和性能测试环境。

---

## 1. 文件清单

```text
db/
  docker-compose.yml
  init/
    00_run_sql_assets.sh
```

`db/docker-compose.yml` 负责启动 PostgreSQL 16，并挂载：

```text
../sql -> /sql:ro
./init -> /docker-entrypoint-initdb.d:ro
```

`db/init/00_run_sql_assets.sh` 只引用 `/sql/V*.sql`，不在 `db/init/` 中维护第二套业务 SQL。

---

## 2. 初始化顺序

默认开发基线初始化顺序：

```text
V1 -> V2 -> V3 -> V4 -> V8 -> V9 -> V10 -> V11
```

其中：

| 文件 | 作用 |
|---|---|
| `V1` | 创建 TPC-H 表 |
| `V2` | 创建 TPC-C 必要表 |
| `V3` | 创建应用辅助表 |
| `V4` | 添加约束 |
| `V8` | 创建触发器 |
| `V9` | 创建存储过程 |
| `V10` | 创建基线索引 |
| `V11` | 加载开发样例数据 |

当 `RUN_BASELINE_VALIDATION=true` 时，脚本还会在初始化阶段执行：

```text
V5 -> V6 -> V7 -> TPC-H 样例查询 -> 存储过程样例调用
```

说明：

```text
V5/V6/V7 中的 PREPARE 语句只在当前 psql 会话内有效，主要用于初始化阶段验证 SQL 模板可执行。
V12__explain_baseline.sql 不默认放进容器初始化，以免每次启动输出大量执行计划；需要时手动执行。
```

---

## 3. 启动数据库

在仓库根目录执行：

```powershell
docker compose -f db/docker-compose.yml up -d
```

查看状态：

```powershell
docker compose -f db/docker-compose.yml ps
```

查看初始化日志：

```powershell
docker logs tpc-commerce-postgres
```

---

## 4. psql 连接

进入容器内连接：

```powershell
docker exec -it tpc-commerce-postgres psql -U tpc_admin -d tpc_commerce
```

如果本机安装了 `psql`，也可以连接：

```powershell
psql "postgresql://tpc_admin:tpc_password@localhost:5432/tpc_commerce"
```

---

## 5. 验证命令

检查表：

```sql
SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'public'
ORDER BY table_name;
```

检查样例数据：

```sql
SELECT 'orders' AS table_name, COUNT(*) AS row_count FROM orders
UNION ALL SELECT 'lineitem', COUNT(*) FROM lineitem
UNION ALL SELECT 'stock', COUNT(*) FROM stock
UNION ALL SELECT 'app_user', COUNT(*) FROM app_user;
```

手动执行 EXPLAIN：

```powershell
docker exec -it tpc-commerce-postgres psql -U tpc_admin -d tpc_commerce -f /sql/V12__explain_baseline.sql
```

---

## 6. 重置数据库

删除容器和数据卷：

```powershell
docker compose -f db/docker-compose.yml down -v
```

重新初始化：

```powershell
docker compose -f db/docker-compose.yml up -d
```

---

## 7. 与 D 的边界

该基线环境包只用于：

```text
1. 验证 A 的 SQL 源资产。
2. 给 B 提供可连接的开发数据库。
3. 给 C 间接提供真实接口联调基础。
```

不负责：

```text
1. dbgen 编译或运行。
2. SF=0.1/SF=0.6/SF=1 正式数据生成。
3. COPY 正式导入脚本。
4. 正式性能测试。
5. 最终 Docker 部署方案。
```
